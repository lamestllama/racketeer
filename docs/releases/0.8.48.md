# 0.8.48 local artifact

Adds cooperative attachment through `racketdap/worker/attach.rkt` API 1.
The attach configuration supplies `port` and `token`, without a program.
Disconnect releases stops and closes the debugger, preserving host lifetime.
Module selection follows the same roots and package settings as launch.

This artifact is for local validation; it has not been published.
TCP transport and installed editor validation require a working loopback
listener and a VS Code extension host. See the embedding host contract in
`racketdap/instrumentation/DESIGN.md` for the public library API.
