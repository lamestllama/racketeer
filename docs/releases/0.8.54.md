# Racketeer 0.8.54 validation

Date: 2026-11-05 (Australia/Adelaide). These results require successful runs of
the [CI matrix](../ci.md).

## Contents

- A hover reads the binding the name refers to where it is written, from the place the editor
  sends with the request. Each form quotes what each name it writes refers to, so the compiled
  cache keeps it. A request with no place goes by name, as before.
- A rename whose pass finds a file changed under its analysis runs a fresh pass, rather than being
  refused with "Resolve its errors". Sources that keep changing end in their own refusal.
- The debugger tells the editor about a breakpoint only when its answer changes, not for each
  form that follows it.

The last two come from repeated CI runs of one commit of 0.8.53, in which each of those tests
failed once.
