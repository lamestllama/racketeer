# Racketeer 0.8.53 validation

Date: 2026-11-05 (Australia/Adelaide). These results come from the [CI matrix](../ci.md) on
GitHub.

## Contents

- A breakpoint on a line with no place to stop, such as an empty line or a comment, moves to
  the next line that has one, which can be in the next function. With none later it stays
  unverified. An inline breakpoint stays on its line.
- The debugger leaves the `#%foreign-inline` form of Racket 9.2 as it is, so a program that
  uses it can be debugged.
- A captured source tab has basic colouring only. A stop opens one only when a saved edit has
  left the running text behind, or for a WXME document, and the language server cannot
  answer for text the file no longer holds. The private `racketeer/sourceReferences` request
  is gone.
- The language server moves to upstream commit `23e1989`, which holds the three pull requests
  it carried as patches.

The tests changed as well. Each waits for a condition through one shared wait with one
long deadline, so a slow machine cannot fail it. No test step has a time limit of its own.
A run's temporary folders go at its end, so cleanup cannot fail a test.
