# Racketeer 0.8.51 validation

Date: 2026-11-03 (Australia/Adelaide). These results cover
the recorded local environment; the other platforms and editor versions require
successful results from the [CI matrix](../ci.md).

## Contents

- When Magic Racket's language server keeps Racketeer's language tools off, Racketeer
  offers to turn off only that server and reload the window. The notice stays until it
  is answered or dismissed, and is not shown again after that.
- Three tests wait for a process number instead of reading a file that may still be empty.
- Linux CI runs on every push, and macOS and Windows on demand.

## Results

Real VS Code 1.144.1 on Linux ARM64, Racket 9.1, with Magic Racket 0.9.0 and a working
language server for it, on a fresh profile:

| Step | Result |
| --- | --- |
| Open a Racket file | The status bar shows `Racket: external LSP`, and the notice is offered |
| Accept the notice | `magicRacket.languageServer.enabled` is `false` in user settings, and the window reloads |
| After the reload | The status bar shows `Racket: ready`, and hover answers from the bundled server |
