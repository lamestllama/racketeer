[Validation archive](0.7.0-validation.zip) contains the reports, logs, artifact
hash and environment record. Native instrumentation and document tests were
run on their unchanged sources before the final adapter lifecycle adjustment;
the protocol, GUI and installed-extension checks cover the final artifact.
The environment was Linux ARM64, full Racket 9.1 CS, VS Code 1.98.1 and Node
20.20.2. These results do not establish other platforms or versions.

The installed tests exercise breakpoints, source highlighting, lexical
inspection and mutation, stepping to termination, persistent REPL interaction,
language-server restart/recovery, and package operations in a private scope.
Package checks include an installed source change after archive update,
metadata-aware native tests, a blocked task's cancellation and child cleanup,
and source debugging in a linked package outside the workspace.

The Test Explorer check also stops inside a real repository test, reads a live
local, verifies an intentionally failing assertion and its source location,
restores the assertion, and exercises repeated Debug REPL calls through four
nested source files. Only its disposable workspace is edited.

The final adapter returns an empty thread list after termination, allowing a
late editor refresh without reporting a nonexistent active program. Other
execution requests remain invalid after exit. Protocol regressions cover both
normal completion and abnormal target exits.

## Reproduce

From the repository root, with full Racket, Node.js 20+, Python 3, VS Code and
Xvfb available:

```sh
npm ci --prefix vscode
node scripts/package-extension.js
raco test tests/*.rkt experiments/lexical-eval.rkt
node --test --test-concurrency=1 tests/dap.test.js tests/annotator-conformance.test.js tests/debugger-parity.test.js tests/workflows.test.js tests/packages.test.js
python3 scripts/test-gui.py
python3 scripts/test-vscode.py
python3 scripts/test-vscode.py --dogfood
PLTCOLLECTS="$PWD/vendor/collects:" raco test vendor/collects/racket-langserver/tests/lib/doc-test.rkt
```

Pass `--xvfb` and `--code` to the editor harness if they are not on PATH.
Reproduce bundled sources with `python3 scripts/vendor-language-server.py`;
this verifies pinned archive hashes before applying the documented local patch.
A rebuild may have different archive timestamps; verify its contents and record
its own artifact hash before distributing it.

## Remaining work

Windows, macOS, Linux x64, a supported version matrix, remote development,
network package failure cases and long-session/resource measurements still
need validation. Test Explorer is file based; native Test Package implements
package metadata policies. The language client selects one Racket installation
per editor window. See [the debugger feature matrix](../parity/DEBUGGER.md)
and [quality requirements](../quality.md) for the full boundaries.

Cross-language control transfer to other debuggers is not implemented
or claimed by this release. The checks here do not establish that capability.
