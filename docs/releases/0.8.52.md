# Racketeer 0.8.52 validation

Date: 2026-11-04 (Australia/Adelaide). These results cover
the recorded local environment; the other platforms and editor versions require
successful results from the [CI matrix](../ci.md).

## Contents

- Debugging a file no longer opens a read-only copy of it in a new tab on every run. A stop
  shows the file itself. A captured copy appears only when a saved edit has left the running
  text behind, or for a WXME document.
- A breakpoint answer names no source, so a breakpoint stays on the name it was set on and
  F9 removes it, whichever name the file was opened under.
- A breakpoint set in a captured copy ends with its session.
- A breakpoint set in the file after a saved edit stays unverified and says to restart. One
  already placed stays where it was.
- The `source` request accepts a source named by its path, as the protocol allows.

## Results

The program from the report: a 1482-line file that converts 115 maps with a large amount of
file input and output, in real VS Code 1.144.1 on Linux ARM64 with Racket 9.1. Plain Racket
takes 19 s.

| Step | This version | 0.8.51 |
| --- | --- | --- |
| Debug Current File three times, previews off | The file's tab only | The file's tab and three read-only copies |
| Run to the end, first and second run | 150 s, 148 s | 153 s, 139 s |
| Stop inside the 879-line function | 1.7 s | 1.6 s |
| Open its 36 locals | 5 ms | 4 ms |
| 25 steps, median and slowest | 4 ms, 56 ms | 2 ms, 13 ms |
| Logpoint hit 2,310,740 times | 472 s | Not measured |

The timings are single runs, so small differences are not significant.

## Suites on this commit

`tests/breakpoint-spelling.rkt` and the new breakpoint and source tests pass. A saved edit
that moves a breakpoint, and a CRLF source, each fail their test when the behaviour is removed.

The build just before this commit differs from it by the position of one line and by test
changes. On it, the installed extension passed in VS Code 1.144.1 and 1.91.0, and the GUI
regressions and editor orchestration checks passed. The whole headless suite last ran on an
earlier form of this change: 697 passed, 15 skipped, none failed, with 273 Racket tests
passed. Rhombus and the repository tests through Test Explorer also last ran on that form. CI
on this commit covers the suites again.

## Known limit

If a program denies file reads at the moment it stops, that stop shows the captured copy
instead of the file.
